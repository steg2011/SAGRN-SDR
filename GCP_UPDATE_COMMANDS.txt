OPTION 1: QUICK UPDATE (Single Command)
================================================================================

Run this if your GCP VM already has the update script:

    sudo /opt/sagrn-sdr/scripts/update_gcp.sh


================================================================================
OPTION 2: MANUAL UPDATE (Copy & Paste All Commands)
================================================================================

# SSH into your GCP Debian VM
gcloud compute ssh sagrn-vm --zone=YOUR_ZONE

# Update system packages (optional)
sudo apt update && sudo apt upgrade -y

# Navigate to SAGRN directory
cd /opt/sagrn-sdr

# Fetch latest from GitHub (main branch = production)
sudo git fetch origin main

# Switch to main branch (production)
sudo git checkout main

# Pull latest changes
sudo git pull origin main

# VERIFY you have v2.0
sudo git describe --tags

# Navigate to frontend directory
cd frontend

# Install npm dependencies
npm install

# Build production bundle
npm run build

# Return to main directory
cd ..

# Restart SAGRN service
sudo systemctl restart sagrn-sdr

# Check service status (should show "active (running)")
sudo systemctl status sagrn-sdr

# View last 20 lines of logs
sudo journalctl -u sagrn-sdr -n 20


================================================================================
OPTION 3: FULL UPDATE WITH VERIFICATION
================================================================================

Run these commands in order and check output after each step:

# 1. SSH into GCP VM
gcloud compute ssh sagrn-vm --zone=YOUR_ZONE

# 2. Check current version
cd /opt/sagrn-sdr
echo "Current version:"
git describe --tags

# 3. Update system packages
echo "Updating system packages..."
sudo apt update
sudo apt upgrade -y

# 4. Fetch latest code
echo "Fetching latest from GitHub..."
cd /opt/sagrn-sdr
sudo git fetch origin main

# 5. Switch to main branch
echo "Switching to main branch (production)..."
sudo git checkout main

# 6. Pull latest changes
echo "Pulling latest changes..."
sudo git pull origin main

# 7. Verify version is v2.0
echo "Verifying version..."
git describe --tags

# 8. Build frontend
echo "Building React frontend (this takes 1-2 minutes)..."
cd frontend
npm install
npm run build

# 9. Return to main directory
cd /opt/sagrn-sdr

# 10. Stop the service
echo "Stopping SAGRN service..."
sudo systemctl stop sagrn-sdr

# 11. Restart the service
echo "Starting SAGRN service..."
sudo systemctl restart sagrn-sdr

# 12. Wait 5 seconds for service to fully start
sleep 5

# 13. Verify service is running
echo "Service status:"
sudo systemctl status sagrn-sdr

# 14. Check for any errors in logs
echo "Last 20 log entries:"
sudo journalctl -u sagrn-sdr -n 20

================================================================================
TROUBLESHOOTING
================================================================================

IF SERVICE DOESN'T START:

1. Check logs for errors:
   sudo journalctl -u sagrn-sdr -n 50 -e

2. Try restarting service:
   sudo systemctl restart sagrn-sdr
   sleep 5
   sudo systemctl status sagrn-sdr

3. Check if frontend built correctly:
   ls -la frontend/build/
   # Should show "static" folder with files

4. Rollback to previous version:
   cd /opt/sagrn-sdr
   sudo git checkout HEAD~1
   cd frontend && npm run build && cd ..
   sudo systemctl restart sagrn-sdr


================================================================================
LIVE LOG MONITORING
================================================================================

Watch real-time logs while the system processes incidents:

    sudo journalctl -u sagrn-sdr -f

(Press Ctrl+C to exit)

To see logs from last 5 minutes:

    sudo journalctl -u sagrn-sdr --since "5 minutes ago"
